# 枪豆人 AI — 方案综述 (v0 草案)

> 状态：算法=PPO ✅、预热=脚本教练(BC→PPO) ✅ 已拍板；其余待定见 §8。本文只做设计，不动代码骨架。
> ⚠️ 执行顺序铁律：**感知(YOLO/弹幕/OCR)先行 → 状态融合 → 脚本教练/BC → PPO**。感知不通，策略层无从谈起。

## 0. 固定配置（已锁定）
- 角色：**小草**（基础3 + 3 = 6 生命上限，无特殊机制）
- 武器：**霰弹枪**（3发，短距离，瞬发扇形AoE，大后坐力；连击档位升→扇形加宽加长；档位色 白→蓝→黄→红）
- 模式：**简单·无限模式**（特效最多叠加1-2个）
- 训练目的：先学会核心循环「瞄准射击 / 后坐力挪位 / 弹药·命中纪律 / 躲弹幕 / 吃果 / 连击维持」
- 训练方法：**PPO**（混合动作：连续瞄准 + 离散开火）；预热 = **脚本教练 → BC → PPO**

## 1. 感知层（三子层，时间上解耦）

| 子层 | 技术 | 目标 | 输出 |
|---|---|---|---|
| L1 大目标 | YOLO | 玩家船、敌人（手/花/藤蔓/海盗/幽灵/电锯/Boss/环境物） | 类别+bbox；**形态优先做类别**，抗黑白/蓝图 |
| L2 弹幕/几何 | OpenCV（HSV+轮廓） | 弹幕→危险栅格；掉落物(红/蓝/星果+闪烁)；弹药点(黄点)+装填弧；瞄准扇形(档位色+方向+范围) | 扇区×距离栅格(2-4帧叠加)、pickup列表、弹药计数、瞄准向量 |
| L3 语义/数值 | OCR(Windows引擎)+模板 | 联机档位(头顶数字=主源,特效下色仍保留)、HP白心/蓝命(左上,模板计数)、钻石数、特效公告大字(FX-ID+开始/结束)、"恢复正常" | 档位、HP/命、钻石、当前特效multi-hot+事件 |

**原则**：形状管分类，颜色只在小 ROI 管状态；语义指示器(弹药/血/连击色)特效下重映射保可读，氛围色(扇形/弹丸)才被消解。

**特效安全通道**：档位→头顶数字色（全程可读）；弹药/装填→FX配色映射表(正常=黄/黑白=黑·白/蓝图=蓝·白) + 内部估计器兜底。

> 📐 **M0b 感知细节已单独成文**：`docs/m0b_perception_design.md`（玩家中间出生逐帧定位、扇形感知=瞄准/范围/弹药/档位四合一、大字模板表、HUD ROI、结算面板评估指标、调暗夜归一、波次/时长指标）。

## 2. 状态向量（示例，喂给决策网络）
- 自身：HP归一、蓝星临时层、当前弹药、装填进度、当前连击档位、瞄准方向(极角)、换弹中、当前特效multi-hot、已存活时长/Boss计数、是否Boss奖励段、商店事件阶段(无/停留中/离场中)
- 敌人：按类型聚合（每类最近K个：相对角度、距离、是否进入前摇/冲刺/泡泡/可杀(幽灵仅光照)/护甲层数）
- 弹幕：扇区×距离×(2-4帧)危险栅格
- 掉落物：最优先pickup（类型、相对位置、is_blinking）
- 提示：坐标统一**以玩家为原点的极坐标**，地图边缘无缝(环形距离)。

---

## 3. 动作空间
- 连续：**瞄准方向** angle（或 (aim_x, aim_y)），范围[-1,1] 对应摇杆
- 离散：**开火** (0/1)
- 决策频率：建议 10–20 Hz（截屏取到对应频率；弹幕层可更高）
- 注：本方案不用机器人（自动锁敌会拿掉瞄准自由度）

## 4. 训练方法（核心选型）

### 候选
- **A 纯模仿学习(BC)**：人示范→直接学。快，但受示范质量/分布偏移限制（土豆兄弟已证实“分布偏移是最大敌人”）。
- **B 纯 RL**（PPO/SAC/DDPG）：上限高、自主，但从零探索慢，奖励需由感知/OCR自提取。
- **C 混合 → ✅ 已拍板**：**脚本教练**批量生成示范 → **BC 预热** → **PPO** 微调。

### 理由与本方案适配
- 状态已结构化到低维向量 → 决策网络用 **MLP（+可选 GRU/LSTM 处理时序，如弹药回复/连击维持/前摇）**，不需要像素级 RL，算力省、样本效率更高。
- 连续(瞄准)+离散(开火) 混合动作：PPO（clipped）适合；若追求稳定可用 SAC 处理连续部分。
- 预热来源：先用手写的“脚本教练”（基本走位+对着最近敌开枪+保持弹药底弹+离爆喷花距离）批量生成示范，能替代大量人工录制，且 24h 可用。**教练规则直接采用官方商店提示**（见下：生命优先、必要时空枪保命、装填被追可空枪打断装填逃生）。

### 奖励草案（可调）
- 每发命中：`+ w1 * (1 + 档位)`（连击加成让高连续击更有价值）
- 空枪(有弹未命中)：`- w2`（**小惩罚**——官方提示"生命比连击重要、必要时开空枪躲避"，罚重了 AI 不敢保命空枪）；**装填期干打(弹匣空时开火)不断连击、无空枪惩罚**，只有装填进度损失
- 受伤/掉血：`- w3 * HP损失`（HP 规则化；**权重应高于连击得失**。受击会触发冲击波推开周围敌人→短暂安全窗口，可被策略利用）
- 拾取：红/星果 `+w4*(缺HP时更高)`；蓝果 `+w5`；钻石 `+w6`
- 连击档位每次爬升：`+w7`（一次性）；持续维持有小正奖励倾向
- 击败 Boss：`+大`；存活时间：小正奖励 + 非终止
- （可选）打空弹匣：`- 小惩罚`（火力真空代价；也可不加，由机制自体现）

> 塑形奖励只用于加速，不锁死策略；最终以真实 HP/连击/钻石为准绳。

### 官方商店提示 / 机制确认（听雨 2026-09-04）
- 商店只卖与当前角色/武器相关的商品（对当前配置无提升的不出现）→ 商店决策空间天然受限
- **商店船时序**：从上缘进入 → 中部停留有限窗口 → 到期向下离场；若进场瞬间就进入，出店后立即离场；**全程仅一次购买机会，离场后无法找回** → 战斗期训练把商店当"事件门控"(不购买、等它自走或暂停)；Phase2 购物策略需在单次窗口内决策
- **3 碎钻 = 1 钻石**（碎钻掉落自钻石电锯等；钻石账目需含碎钻换算）
- **蓝星 = 临时生命值**（不受生命上限约束，本质是"额外护甲层"，非永久命）
- **受击触发冲击波，推开周围敌人** → 受击并非纯负面，会制造短暂脱困窗口
- 官方策略：连击重要但**生命更重要**；必要时可**开空枪借后坐力躲避**（代价=断连击）
- 装填中被敌人追上 → 可开空枪(干打)借后坐力躲避：**打断装填进程但不影响连击**（区别于"有弹打空"的空枪——那种才断连击）→ 装填期干打 = 无连击代价的位移工具，代价只有装填进度（反复干打会永远装不完）
- 物理弹命中**幽灵**(无伤害) 也不算空枪 → 连击保留（幽灵=免疫伤害但可"蹭连击/安全位移"的目标）

> 以上直接决定：奖励权重 **HP > 连击**；脚本教练(M1)的保命规则 = 官方提示的"可执行版"。

### 屏幕大字 / 状态公告词表（OCR·L3 层用，听雨 2026-09-04）
| 屏幕大字 | 触发/含义 | 用于状态 |
|---|---|---|
| 恢复正常 | 特殊效果结束 | 特效结束事件 → 从当前特效集合移除 |
| 奖励时间 | 击败 Boss 后的奖励段 | 进入 Boss 奖励段 flag |
| （Boss 名称） | Boss 登场 | 当前 Boss id |
| （特殊事件名称） | 特殊事件开始(结冰/夜幕/黄昏等) | 向特效 multi-hot 添加 |
| 葬身大海 | 玩家死亡 | 回合终止 / 结算触发 |

### ⚠️ "夜晚"有两种子态（区分很重要，听雨确认）
- **真·夜晚(特效)**：仅手电筒照亮范围可见，其余全黑 → 会以大字公告；按"有限视野"处理（感知只能靠自身光/瞄准方向聚光）。
- **调暗夜(过渡/普通)**：画面整体变暗、瞄准方向有聚光，但**敌人仍全部可见、无大字公告** → 感知口径 = 亮度低但仍可读：需 CLAHE/伽马自适应提亮 + 颜色层降阈值/兜底；聚光方向可作瞄准方向辅助线索。
> 本轮 3 张实战图 = 1 白天 + 2 调暗夜 → 属 YOLO 补数据素材，可直接并入 has_target / real_batch。

### 特殊事件词典 — 简单·无限 全集（听雨 2026-09-05）
> 也是 L3 大字模板的事件名清单 & 特效 multi-hot 维度全集。

**物理/操控类**：弹力球、上下弹力墙、绳子、上下洋流、环形洋流、缆车、上下传送、左右传送（边缘穿梭→环形距离）、磁力准星（准星被吸附，瞄准自由度受限）

**视觉类（简单里为轻度）**：黄昏、夜晚（调暗夜：变暗但全可见）、暴风雨

**电锯家族**：电锯、大电锯、加倍电锯、角落电锯、移动电锯（固定轨道来回）、砰砰电锯（粉色，**每次开枪触发**其在轨道上移动）、绳子电锯（场地中央绳拴）、溜溜球电锯（**绳拴在玩家船上**）、电锯摩托车、电锯船

**区域/陷阱类**：淤泥（减速：**玩家/海盗/电锯受影响，手类不受**）、毒（毒圈内积累毒素→满则受伤；出圈进度回退）、小心鲨鱼（黄线警戒区，进入引鲨鱼**无差别攻击所有单位**）

**时间/物理反转类**：时间乱流（时间忽快忽慢 → 环境动力学不稳）、后坐力反转（**后坐力由后变前 → 瞄准/移动逻辑反转**，必须高显性）

> ⚠️ **纯视觉事件（黑白/蓝图/万花筒等）只在困难模式出现**；简单·无限无纯视觉事件 → v1(简单)大字模板只需上表事件名 + 固定公告（恢复正常/即将出现+Boss名/奖励时间/葬身大海）。

**对 RL/教练的编码影响**：
- 事件种类多且物理语义各异 → 特效 multi-hot 是**策略条件化的主键**；每个事件配"影响哪些单位/动作"的行为注记（淤泥只减速非手类、砰砰电锯吃玩家开火、溜溜球电锯跟着玩家、后坐力反转要单独高亮、磁力准星限制瞄准自由度、鲨鱼区无差别、时间乱流需决策频率自适应）。
- 大字模板需要采集的事件公告 = 上表；固定公告另计。

## 5. 课程（核心路线）
- S0 感知管线调通 + 标定（截图库、特效样本库、HSV/档位色板、OCR大字词表）
- S1 稳定瞄准·不开空枪（低密度敌情）
- S2 后坐力走位·躲基础弹幕
- S3 弹药·命中纪律 + 连击维持
- S4 安全接敌距离（击杀爆喷花）+ 吃果/蓝果
- S5 特殊事件（结冰/夜幕/幽灵）+ 多特效叠加
- S6 困难模式

## 6. 工程要点 / 风险
- 截屏帧率 → 决策频率；16倍速可能混叠，**建议 4–8 倍起步**
- 敌我弹撞色（黄/红档位）→ 颜色优先 + 出生点/方向兜底
- 特效下感知回退（内部状态估计器家当）
- 云端：Windows GPU VM 单机闭环（vgamepad 本地 XInput）；真并行= 多实例/多 Steam 账号
- 时间加速依赖引擎 timeScale（大概率 Unity → CE 类工具）需验证
- 该游戏对“同机多手柄/多输入”敏感 → AI 运行时拔真实手柄，只留虚拟手柄

## 7. 里程碑（建议）
- M0a **感知数据工程（第一个动手项）**：录素材(简单无限初期/特效事件) → 定 v1 类别清单 → 标注(tlou2 工具链) → YOLO v1 训练
- M0b 感知补齐：危险栅格(颜色层)+OCR(档位/HP/特效大字)+状态融合 → 实时输出状态向量
- M1 脚本教练跑通：吃 M0 的状态向量，启发式能活着打几局(批量出示范)
- M2 BC/预热：模仿教练学到基础行为（不开空枪、会躲）
- M3 RL 上线：小草+霰弹枪在简单无限模式达到“稳定活过 X 分钟”
- M4 全机制：吃果/连击维持/Boss/特殊事件
- M5 困难模式泛化
- M6 云端 24h 多实例批量训练
