# 枪豆人 (Bang Bang Barrage) — 敌人/Boss 类型-行为表

> 用途：作为感知层(YOLO分类)与决策层(RL先验/奖励/课程)的公共知识库。
> 由听雨讲解整理。标注 ❓ = 需要实测/确认的数字或模糊点。

## 0. 核心分类维度

每个敌人类型用以下字段描述：
- **外观**：YOLO 分类依据（剪影/颜色，形态优先）
- **出现条件**：普通 / 特殊事件(结冰,夜幕) / Boss奖励关 / 常态
- **移动**：静止 / 缓慢 / 追逐 / 随机 / 特殊
- **威胁语义**：接触伤害 / 死亡爆喷 / 概率型(视阈) / 远程瞄准 / 冲刺 / 幽灵(仅光杀)
- **击杀难度**：命中次数
- **爆喷弹道**（如适用）：颜色+方向

## 1. 手类（海面[或冰面]伸出的手，形态固定）

| 类型 | 外观 | 出现条件 | 移动 | 行为 |
|---|---|---|---|---|
| 抓抓绿手 | 绿手 | 常态 | 静止 | 接触玩家受伤 |
| 点赞橙手 | 竖起大拇指橙手 | 常态 | 随机方向 | 随机移动 |
| 比耶红手 | 庆祝V字红手 | 常态 | 追踪最近玩家 | 走走停停 |
| 追追紫手 | 紫手 | 常态 | 持续追踪最近玩家 | 持续追 |
| 钻石手 | 戴钻石戒指手 | **Boss奖励关** | 静止 | 击杀掉1颗钻石，漂浮海面；成群 |
| 乱跑钻石手 | 戴钻石戒指手 | **Boss奖励关** | 随机方向 | 成群乱跑；击杀掉1颗钻石 |
| 钻石手镯手 | 戴手镯手 | 常态 | 飞快乱跑 | 击杀后掉落**3颗**钻石 |
| 心心果手(红果手) | 托红果手 | 常态 | 随机移动 | 掉落红果；红果无人捡会沉入海底 |
| 原地心心手 | 托红果手 | 常态 | 静止 | 掉落红果；同左 |
| 蓝心心果手 | 托蓝果手 | 常态 | 随机方向 | 掉落蓝果 |
| 否定蓝手 | 蓝手 | 常态 | 垂直方向 | 成群出现、垂直移动 |
| 转转6手 | 黄手 | **仅困难无限** | 绕目标打转 | 螺旋迂回接近 |
| 冻僵手 | 冻僵手 | **仅困难·结冰事件** | 无法移动 | 无移动 |
| 黄手套手 | 戴黄手套手 | 常态 | 平时悠闲移动 | 外层黄手套被打掉后，**剩下的手**追击玩家 |
| 红手套手 | 红手套内套黄手套(双套) | 常态 | 悠闲 | **需打3发**（红手套→黄手套→本体）；外层红手套被打掉后，剩下的手追击玩家 |
| 爱心手 | 连在一起的爱心手 | **仅困难无限** | 移动 | 被打散后两个都追击玩家；分开 |

> 手套层 = 额外护甲/血条；所有"被打掉外层手套"的情况，追击玩家的都是**剩下的本体手**。

## 2. 花类（从场地边缘向内生长 / 独立花，击杀触发爆喷）

| 类型 | 外观 | 弹道(被击中后) |
|---|---|---|
| 十字花(红花) | 红色四瓣花 | 上/下/左/右 4 向 + 红色花瓣弹 |
| 斜十字花(黄花) | 明黄色四瓣花 | 4 斜角 + 黄色花瓣弹 |
| 铃兰 | 面朝玩家出生，出生后不可转头 | 间歇性单发子弹 |
| 粉铃兰 | 粉色眼珠的铃兰 | 连续发射3发子弹 |
| 炸弹花 | 把头拔下扔向目标 | 落地爆炸，对所有单位伤害(含自己/对方) |
| 毒炸弹花 | — | 持续扔毒炸弹；爆炸留下毒圈 |
| 六角炸弹花 | — | 爆炸后 6 方向发放花瓣弹 |
| 短手炸弹花 | 无法主动扔炸弹 | 被击杀后原地爆炸(范围正常) |
| 短手毒炸弹花 | — | 爆炸后留毒圈 |
| 短手六角炸弹花 | — | 爆炸后 6 向花瓣弹 |
| 大炸弹花 | 个头特别大 | 被攻击后产生**极大范围**爆炸，伤及范围内所有单位(含幽灵/叶子/藤蔓) |
| 白眼球花(之前介绍) | 白色长眼睛 | 发射紫色子弹 |

> 击杀爆喷类 = "击杀死后的反击"，接敌距离是关键。每类弹道确定 → 类型→弹道查表先验。

## 3. 藤蔓类（头部是某物的藤蔓，从场地边缘向内缓慢生长；击中头部会后退，退至边缘即死）

| 类型 | 头部 | 特性 |
|---|---|---|
| 叶子藤蔓(普通藤蔓) | 叶子 | 缓慢生长；击中头部后退，退到边缘死亡 |
| 十字花藤蔓 | 十字花 | 同叶子藤蔓 + 十字花爆喷 |
| 斜十字花藤蔓 | 斜十字花 | 同叶子藤蔓 + 斜十字爆喷 |
| 钻石藤蔓 | 钻石花 | 被攻击后掉落钻石；**仅奖励关卡** |
| 铃兰藤蔓 | 铃兰 | 会发射子弹 |
| 炸弹藤蔓 | 炸弹 | 被攻击后范围伤害 |
| 毒炸弹藤蔓 | 毒炸弹 | 被攻击留毒圈；其余同叶子藤蔓 |
| 六角炸弹藤蔓 | 六角炸弹 | 六角炸弹效果，但藤蔓移动 |
| 幽灵藤蔓 | 幽灵 | 物理免疫，只能手电筒照射；持续后退，退到边缘死 |
| 青蛙藤蔓 | 青蛙 | 会黏住玩家并拉近；击中青蛙舌头短暂松开 |

> 藤蔓是"生长型"威胁，非爆喷类；击退机制(击中后退)提供正反馈。

## 4. 海盗类（人形，手持武器/装饰；分戴帽/不戴帽两型）

| 类型 | 特性 |
|---|---|
| 普通海盗 | 用手枪攻击；帽子可挡一次伤害 |
| 转转盾海盗 | 盾绕身体旋转，挡下刚好来自盾面的攻击 |
| 持盾海盗 | 出场面向玩家；需绕到其他方向攻击（红激光瞄准预警→发射红弹） |
| 电锯头海盗 | 被击中掉下电锯；之后变普通海盗 |
| 十字花海盗 | 头戴十字花；被攻击后十字花4向爆喷，之后变普通海盗 |
| 斜十字花海盗 | 头戴斜十字花；多数与十字花海盗同现；被攻击后4斜角爆喷 |
| 兰铃海盗 | 铃兰面朝玩家自动射击，每次一发 |
| 雪橇海盗 | 仅结冰事件；冻得发紫、速度飞快 |
| 牛仔海盗 | 扔绳子拴住玩家；其余同普通海盗 |

> 海盗多数有"帽子=护甲/盾=定向格挡/十字花=死亡爆喷"的结构，属多层血条+定向弱点型。

## 5. 幽灵类（物理免疫，只能用光/手电筒杀死；出现于黄昏/夜晚，部分种类不分时段）

| 类型 | 特性 |
|---|---|
| 呆呆幽灵 | 夜幕出现；原地漂浮；物理免疫；仅光线可杀（手电筒照死） |
| 追追幽灵 | 慢慢跟在目标后面；光线杀 |
| 帽子幽灵 | 戴帽；不怕光线；**不分时段**出现；需先打掉帽子再照射致死 |
| 钻石幽灵 | 戴紫帽；被击杀后掉钻石；**仅奖励关卡**（同乱跑钻石手） |
| 持盾幽灵 | 盾面朝玩家；盾挡该方向光线；需绕到其他方向照射 |
| 炸弹幽灵 | 被照射死亡后产生物理爆炸；伤及幽灵以外所有单位（含玩家、敌人） |
| 六角炸弹幽灵 | 同炸弹幽灵；死亡后再发射6枚花瓣子弹 |

> 幽灵 = 光线武器(手电筒)特化类；且手电筒光线方向与玩家瞄准方向一致（用户明确）→ 瞄准方向决定光线路径。物理弹命中幽灵不造成伤害，但**不算空枪、连击保留**。

## 6. 电锯类（实体障碍/攻击型；物理伤害）

| 类型 | 特性 |
|---|---|
| 橙色电锯 | 被击中后沿攻击方向冲刺，伤害沿途所有单位；每击留下裂痕，最终碎裂 |
| 双电锯 | 用绳子连接的两个电锯 |
| 钻石电锯 | 闪亮钻石电锯；被击碎后掉落碎钻 |
| 小电锯 | 黄色小电锯；冲刺更快，但更易碎（撞2次就碎） |
| 好奇电锯 | 被最近准星(玩家Aim)自动框住吸引；难缠但可用它攻击周围敌人 |

> 电锯 = 可被"利用"的物理环境物（尤其好奇电锯可反制）。属"伤害+工具"。**准星吸附**是独特机制。

## 8. 供 RL 编码的重点结论

1. **出现条件分级 → 课程 & YOLO 分期**：
   - 普通敌人（常态）为主训练集
   - 特殊事件专属：冻僵手/雪橇海盗(结冰)、幽灵类(夜幕)、藤蔓+大炸弹花(场内生长)、牛仔/绳子(常态)
   - Boss奖励关专属：钻石手/乱跑钻石手/钻石幽灵/钻石藤蔓
   - 因此**YOLO 类别卷按课程渐进扩充**，先标"简单无限模式初期(低难度/时间前段)会遇到的类"。

2. **威胁语义分五族 → 每族打法不同**：
   - 接触/追逐手爪类 → 走位躲避（比耶红/追追紫/爱心/红手套追击）
   - 死亡爆喷花/藤蔓 → 安全击杀距离
   - 远程瞄准/定向墙体（海盗:激光预警/持盾/持盾幽灵、铃兰、炸弹花头）→ 提前躲/绕攻
   - 幽灵特化 → 需绕开盾/先打帽，仅光杀
   - 电锯/环境物 → 可利用/规避

3. **颜色与档位色板撞色**：敌方弹 {红,黄,紫,橙} vs 自家白/蓝/黄/红 → 黄、红两档撞色，需出生点/方向兜底。

4. **幽灵/光线机制**：手电筒光线方向 = 玩家瞄准方向（用户确认）→ 瞄准方向同时决定"射弹+后坐力+光线路径"。

5. **多层血条/定向弱点**：帽子、盾、手套(红/黄双套)、鬼火、十字花冠、电锯头 → 均为"结构护甲"，YOLO需区分"本体 vs 护甲已破"状态或由命中次数动态更新。

6. **持续刷怪 + HUD 有"波次"计数**：敌人持续刷新（无清晰波次间隔）；但顶中 HUD 存在 `波次：N` 计数器与 `游玩时长`（2026-09-05 截图确认）→ 评估指标用 **波次 / 存活时长 / 击败Boss数 / 得分**；击败 Boss 后短暂进入"奖励敌怪"段再刷新。特殊事件(黄昏/夜晚/结冰)部分固定波次触发、部分随机。

## 10. 待确认/需实测 ❓

- ✅ 已确认：黄手套/红手套 → 外层被打掉后是**剩下的手**追击；钻石掉落 → 仅手镯手=3颗、其余钻石手=1颗；幽灵出没于黄昏/夜晚、部分类型不分时段；特殊事件(夜幕/结冰)部分固定波次、部分随机；无明确波次、持续刷怪，仅 Boss 后短暂奖励段再刷新。
- 各弹速/爆喷半径/前摇时间（红色激光时长、铃兰发射间隔等）→ 录屏标定
- 叶子/藤蔓生长速率、击中后退距离
- 黄昏/夜晚/结冰事件的确切触发条件（哪些固定、哪些随机）
- Boss奖励关如何触发、奖励敌怪持续时长
- 大炸弹花爆炸范围数值；电锯冲刺速度/碎裂条件
