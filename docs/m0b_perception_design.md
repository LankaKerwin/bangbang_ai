# 枪豆人 M0b — 感知管线设计（视觉侦察版）

> 基于 2026-09-05 实战截图侦察 + 听雨确认。前接 `plan_overview.md` §1。

## 0. 关键修正与事实（重要）
- **玩家出生在屏幕中间**，位置逐帧变化，左下角只是局部巧合 → **玩家坐标必须每帧由 YOLO/定位给出，不能假设固定**。
- **存在"波次"计数器**：顶中 `波次：N` + `游玩时长 MM:SS` → 作为**评估/课程指标**（比纯时长稳）；敌人刷新虽连续，但波次/时长可作为进度标尺。
- **夜晚 = 调暗夜**：深蓝底变暗但敌人**全彩可见** → L2 前做**亮度/对比度归一**（CLAHE/伽马）即可，颜色层仍可用。
- **大字 OCR 失效**（艺术大字被当图形）→ L3 大字用**模板匹配**，不用 OCR。

## 2. L2 颜色/几何（本阶段核心）

### 2.1 瞄准扇形（霰弹枪）→ 甲级状态源
- 视觉：玩家处半透明扇形，朝瞄准方向张开；外缘一条**细黄弧线**，弧上 **3 个小黄点 = 弹药**。
- 提取：
  - **扇形角平分线 = 瞄准方向**；**扇形半径 = 攻击范围(AoE)**
  - 弧上**黄点数量 = 当前弹药**（黄实=有弹，空/转=无弹）
  - 扇形内部**颜色 = 连击档位**（白→蓝→黄→红）
- 做法：在玩家 bbox 附近找扇形扇区轮廓 + 黄弧线，拟合几何；或把玩家→黄弧的方向/半径直接量化。
- 用途：瞄准方向 / 攻击范围 / 弹药 / 档位（一个特征源四用）。

### 2.2 弹幕危险栅格
- 敌方弹色板：{红,黄,紫,橙}；颜色过滤 + 汇总成 **扇区×距离** 栅格（2–4 帧叠加）。
- 敌我弹分流：颜色优先 + 出生点/方向兜底（自家档位黄/红与敌弹撞色时）。

### 2.3 掉落物
- 红果/蓝果/星果：颜色识别；位置固定（不追）；**消失前闪烁** → `is_blinking` 标记。

## 3. L3 语义（OCR / 模板）
### 3.1 HUD 小字（OCR，固定 ROI）
- 左上：**白心(实/空心)** 血量 + **蓝心(临时命)**
- 顶中：`MM:SS` 时长 + `波次：N`
- 右上：`◆ N` 钻石 + 分数
> RIO 固定，模板/OCR 均可；建议先标几张 HUD 图做模板。

### 3.2 大字（模板匹配，勿 OCR）→ 状态公告
| 大字 | 状态用途 |
|---|---|
| 恢复正常 | 特效结束（从特效集合移除） |
| （特殊事件名，如"毒"） | 特效开始（加入 multi-hot） |
| 即将出现 + （Boss 名） | Boss 登场预警 → Boss id |
| 奖励时间 | 击败 Boss → 奖励段 flag |
| 葬身大海 | 玩家死亡 → 回合终止/结算 |

### 3.3 死亡结算画面（金矿）
标题"葬身大海" + 统计：`最大连击 / 受伤次 / 命中率 / 击杀 / 波次 / SCORE / 剩余钻石 / 战胜大海盗 / BEST`
- 用途：**回合结算 = 精确评估指标 + 奖励锚点**。尤其**命中率**可直接校准"空枪惩罚"权重；击杀/连击/受伤/波次 = 进度指标。

### 3.4 商店阶段
- 顶中**蓝白小船 + SHOP 字样**（模板/轮廓识别）→ 商店阶段；时序：进入→停留→离场（plan_overview 已记）。

## 4. 状态向量（更新版）
- 玩家：**位置(逐帧)**、HP、蓝心、弹药、装填进度、**瞄准方向/AoE**、连击档位、特效 multi-hot、**波次**、**时长**、商店阶段、Boss id
- 敌人：YOLO 类别 + 位置（含 Boss）
- 弹幕：危险栅格；掉落物：位置 + is_blinking

## 5. 评估指标
- **结算面板**：命中率 / 击杀 / 最大连击 / 受伤 / 波次 / 分数 / 剩余钻石 → 主评估
- **训练期实时**：HP / 命 / 时长 / 波次
